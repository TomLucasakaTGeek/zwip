# 🚀 Zwip-AI

**Zwip-AI** is a multi-modal AI-as-a-Service platform that streamlines content creation and image processing. By leveraging the **Google Gemini API** for advanced text intelligence and the **Clipdrop API** for professional visual tools, Zwip-AI allows users and businesses to build and execute high-performance AI workflows.

---

## ✨ Features

### 🧠 Text-Based Services (Powered by Gemini)
* **Article Generation:** Generate structured, high-quality long-form content instantly.
* **Title Generation:** Create compelling, SEO-optimized titles for any context.
* **Resume Review:** Get detailed AI feedback to improve resume impact and formatting.

### 🖼️ Image-Based Services (Powered by Clipdrop)
* **Image Generation:** Convert descriptive text into high-fidelity visuals.
* **Background Removal:** Professional-grade background extraction for clean product or portrait shots.

### 🔐 Infrastructure & Security
* **Clerk Auth:** Secure, modern user authentication and session management.
* **Relational Storage:** Reliable data handling using PostgreSQL via NeonDB.
* **Responsive UI:** A sleek, dark-themed interface built with TailwindCSS and Lucide icons.

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** React.js
- **Styling:** TailwindCSS
- **Icons:** Lucide-React
- **Notifications:** React-Hot-Toast
- **Authentication:** Clerk

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** PostgreSQL (NeonDB)
- **AI Integration:** Google Gemini SDK, Clipdrop API

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- Google AI Studio API Key (for Gemini)
- Clipdrop API Key
- Clerk API Keys
